Support

Find a fix, report a problem or get help testing Glimmer.

Get help

To report a problem or ask a question, open an issue on GitHub. Include your device, its system version, the Glimmer version and what happened.

Prefer email? Write to glimmer-prerelease@ugfugl.io. Don't send pairing PINs or certificates.

Updates and beta testing

Download Glimmer for Mac and release candidates from GitHub Releases. Glimmer updates itself after that.

To test the iPhone and iPad app on TestFlight, email glimmer-prerelease@ugfugl.io with the device you'll test on.
