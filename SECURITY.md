# Security

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/Se7enbrc/glimmer-ios/security/advisories/new).
Include the affected revision, what happened and steps to reproduce it. Do not
post keys, PINs, certificates, provisioning profiles or private logs.

This scaffold does not connect to the PC yet. The development branch is the only
supported version. Shared protocol issues also belong in
[Glimmer’s private reports](https://github.com/Se7enbrc/glimmer/security/advisories/new).
No analytics or third-party network services run in the app.
