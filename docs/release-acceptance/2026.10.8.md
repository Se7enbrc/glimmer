## Final menu timing refinement after rc.22

Owner feedback accepted the controller follow-up with a request to reduce the
iOS menu hold from 2.5 to 2 seconds. The threshold, boundary assertions, help
text and existing journey hold durations are updated together. Focused pure
Swift shortcut tests cover short taps and both sides of the new threshold. The
earlier menu/dismissal receipts remain evidence for their actual source; this
timing refinement does not restart the comprehensive acceptance pass.

Upstream Moonlight iOS and desktop send ordinary Start input immediately and
clear the controller state once all four quit buttons are down. Neither buffers
a Start press that precedes the other buttons. Glimmer retains immediate Start
input and complete-chord suppression; no pause-on-release behavior is added.
