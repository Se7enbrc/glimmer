# Glimmer

Glimmer is a Mac-native client for
[Sunshine](https://github.com/LizardByte/Sunshine). It streams games from your
own PC to your Mac. macOS 26 or later, Apple Silicon. Free, now and always.

New here? [Install Glimmer](INSTALL.md), then [set up the PC](HOST_SETUP.md).

- [Features](FEATURES.md): what Glimmer does, in detail.
- [Shortcuts](SHORTCUTS.md): keyboard and controller shortcuts, copy and paste.
- [Command line](COMMAND_LINE.md): the `glimmer` command.
- [Audio on macOS](AUDIO.md): voice chat, AirPods and volume recovery.

Working on Glimmer itself? Start with [Contributing](CONTRIBUTING.md) and
[Architecture](ARCHITECTURE.md).
