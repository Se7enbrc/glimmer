# Contributing

Start with an issue the maintainer agrees to, then use the guide for your
change.

| You need to…                                      | Read                                    |
| ------------------------------------------------- | --------------------------------------- |
| Set up, build, test and prepare a PR              | [Developer guide](CONTRIBUTING.md)      |
| Find the code and its ownership rules             | [Architecture](ARCHITECTURE.md)         |
| Measure a stream or evaluate a performance change | [Profiling and telemetry](PROFILING.md) |
| Prepare and promote a candidate                   | [Release process](RELEASE.md)           |

Everyone follows the
[code of conduct](https://github.com/Se7enbrc/glimmer/blob/main/CODE_OF_CONDUCT.md).
See [credits](https://github.com/Se7enbrc/glimmer/blob/main/CREDITS.md) for
upstream work.
