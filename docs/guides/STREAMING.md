# Play fullscreen, windowed or in Mini Player

## Start and stop

1. Click a launcher app.

{% hint style="warning" %}

Save before stopping or takeover. Control-Q, closing the window and quitting
Glimmer quit the PC app by default. To keep a game running, turn on “Leave games
running when you disconnect” in Settings. Use this only with games and PCs that
handle a change in screen size.

{% endhint %}

## Continue a running game

1. Select the PC.
2. Choose “Resume” or “Continue here” beside the running game.

Glimmer keeps the previous stream size when it knows it and fits the picture to
your screen. Another device may still be connected. To try a different size,
choose “Use this screen's size…” and save your progress first. A game that
failed that change offers a restart instead.

Select another app to quit the running game and start the new one in a single
confirmed action. “Quit <game>…” remains available when you only want to stop
it.

## Leave the picture running

| Action                | Control           |
| --------------------- | ----------------- |
| Switch Mac apps       | Command-Tab.      |
| Toggle Mini Player    | Control-M.        |
| Restore hidden stream | “Back to stream”. |

{% hint style="info" %}

Mini Player keeps background controller input. Keyboard/mouse follow focus.

{% endhint %}

## Choose a display mode

1. Open Settings › Quality.
2. Choose your next stream's mode.

| Mode            | Picture                                |
| --------------- | -------------------------------------- |
| Sharpest        | Native Mac pixels.                     |
| Balanced        | Half-width, half-height.               |
| Custom          | Resolution, frame rate, window choice. |
| Highest quality | More detail within connection limits.  |

{% hint style="info" %}

Fullscreen fills the panel around the camera by default, without creating a
separate desktop. To swipe away and back, turn on “Keep picture below the
camera” in Settings › Quality, or “Use a full-screen Space” on a display without
a notch. The next stream opens in its own macOS Space. On a Mac with a notch,
the picture stays below the camera. Choices stay saved.

{% endhint %}

## Check video support

{% hint style="info" %}

Control-Z shows format. H.264, HEVC, supported AV1 and HDR10 require compatible
hardware. Custom: 640–7680 × 480–4320, 30–240 fps. PC menu: codec preference.
[Shortcuts](../SHORTCUTS.md): Game Mode.

{% endhint %}
