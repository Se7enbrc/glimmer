# Free the pointer or use game controls

1. Focus the stream.
2. Press Control-P to switch modes.

| Mode         | Controls                                                            |
| ------------ | ------------------------------------------------------------------- |
| Captured     | Relative aim, physical keys; fullscreen default, including Desktop. |
| Free pointer | Point and type using Mac input methods.                             |

{% hint style="info" %}

Window or Mini Player: hold plain Escape about a second to free the pointer. See
[capture shortcuts](../SHORTCUTS.md).

{% endhint %}

## Keep Mac shortcuts available

Command-Tab and Command-Space stay with the Mac by default.

## Paste text into the PC

1. Copy Mac text.
2. Focus the stream.
3. Press Control-V.

{% hint style="info" %}

Up to 4,096 UTF-8 bytes; no files/images.
[Copy on the PC stays there](https://github.com/LizardByte/Sunshine/issues/1539).

{% endhint %}
