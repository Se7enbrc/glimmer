# Free the pointer or use game controls

On Mac:

1. Focus the stream.
2. Press Control-P to switch modes.

| Mode         | Controls                                                            |
| ------------ | ------------------------------------------------------------------- |
| Captured     | Relative aim, physical keys; fullscreen default, including Desktop. |
| Free pointer | Point and type using Mac input methods.                             |

{% hint style="info" %}

Window or Mini Player: hold plain Escape about a second to free the pointer. See
[capture shortcuts](../SHORTCUTS.md).

{% endhint %}

## Keep Mac shortcuts available

Press **Control-Shift-P** to release both keyboard and mouse without stopping
the stream. macOS shortcuts, including screenshots and Command-Tab, work while
input is released, even if Command normally goes to the PC. The stream keeps
playing.

Click the picture or press Control-Shift-P again to recapture input. The click
or shortcut used to return does not reach the game. Moving over the picture,
switching apps, or reconnecting does not silently recapture it. Change the
shortcut in Settings › Input.

Command-Tab and Command-Space stay with the Mac by default. ⌃Q (Control-Q) stops
the stream. ⌃Z (Control-Z) shows or hides stream stats by default. Change saved
bindings in Settings › Input. These two shortcuts also work with a hardware
keyboard on iPhone and iPad.

## Paste text into the PC

1. Copy Mac text.
2. Focus the stream.
3. Press Control-V.

{% hint style="info" %}

Up to 4,096 UTF-8 bytes; no files/images.
[Copy on the PC stays there](https://github.com/LizardByte/Sunshine/issues/1539).

{% endhint %}

## Use touch as a mouse on iPhone and iPad

Use the picture outside the on-screen buttons as a trackpad:

| Gesture           | Action                |
| ----------------- | --------------------- |
| Drag one finger   | Move the pointer.     |
| Tap one finger    | Left-click.           |
| Drag two fingers  | Scroll.               |
| Tap two fingers   | Right-click.          |
| Tap three fingers | Show the stream menu. |

“Touch mouse” in Settings › Input is on by default, including with a controller
connected. Turn it off to prevent accidental mouse input during the next stream.
The three-finger tap still opens the menu. Choose “Resume” to return input to
the PC.
