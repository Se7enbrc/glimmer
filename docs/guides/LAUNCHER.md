# Choose app buttons or cover artwork

On Mac:

1. Open the PC's context menu.
2. Choose Buttons or Covers.

On iPhone or iPad, choose Buttons or Covers in Settings › General › Launcher ›
“Layout”. On Mac, each PC keeps its own choice.

| Style   | Layout                                               |
| ------- | ---------------------------------------------------- |
| Buttons | Four cells; fourth holds extra apps.                 |
| Covers  | One–four columns, two visible rows; scroll for more. |

## Read the current state

On Mac:

| State            | Action                                        |
| ---------------- | --------------------------------------------- |
| Ready            | Click an app.                                 |
| Wake and connect | Wake PC.                                      |
| Trust needed     | Confirm certificate change before re-pairing. |
| Connecting…      | Wait; Escape cancels.                         |
| Back to stream   | Restore stream.                               |

{% hint style="info" %}

Return prefers the running app, then the visible Start with choice from Settings
› General. Login options live there too.

{% endhint %}

## Continue or replace a running game

“Resume” or “Continue here” opens the game already running on the selected PC.
To start something else, select its app and confirm “Quit {game} and start
{app}”, with the names Glimmer shows. Save first: this quits the running game
and stops other streams from that PC.

Disconnecting quits the game by default on Mac, iPhone and iPad. Before
streaming, turn on “Leave games running when you disconnect” in Settings ›
General to keep it available for another paired device. See
[continuation and screen sizes](STREAMING.md#continue-a-running-game).
