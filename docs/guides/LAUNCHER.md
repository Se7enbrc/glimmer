# Choose app buttons or cover artwork

1. Open the PC's context menu.
2. Choose Buttons or Covers.

| Style   | Layout                                               |
| ------- | ---------------------------------------------------- |
| Buttons | Four cells; fourth holds extra apps.                 |
| Covers  | One–four columns, two visible rows; scroll for more. |

## Read the current state

| State            | Action                                        |
| ---------------- | --------------------------------------------- |
| Ready            | Click an app.                                 |
| Wake and connect | Wake PC.                                      |
| Trust needed     | Confirm certificate change before re-pairing. |
| Connecting…      | Wait; Escape cancels.                         |
| Back to stream   | Restore stream.                               |

{% hint style="info" %}

Return prefers the running app, then the visible Start with choice from Settings
› General. Login options live there too.

{% endhint %}
