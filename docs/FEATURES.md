# Choose how you play

Play from the same Sunshine PC on your Mac, iPhone or iPad.
[Pair each device](GETTING_STARTED.md), then choose a game in the launcher. Use
controller layouts and continue running games on each device.

Use touch controls on iPhone and iPad, including while the picture plays on a
connected display. On Mac, use Mini Player, the menu bar, Wake on LAN, the Wi-Fi
helper and command-line tools. The guides explain those device-specific
controls.

To move between devices, enable “Leave games running when you disconnect” before
streaming. Then use
[Resume or Continue here](guides/STREAMING.md#continue-a-running-game) on the
next device. Disconnecting quits the game by default.
