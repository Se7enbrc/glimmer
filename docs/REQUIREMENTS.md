# Check what you need to play

| Part           | You need                                                                                    |
| -------------- | ------------------------------------------------------------------------------------------- |
| Mac            | Apple Silicon, macOS 15.7 or later.                                                         |
| iPhone or iPad | iOS or iPadOS 26 or later. Available through TestFlight now; App Store release coming soon. |
| PC             | Current, unmodified [Sunshine](https://github.com/LizardByte/Sunshine), running and awake.  |
| PC display     | Physical or [virtual](HOST_SETUP.md), supporting your chosen mode.                          |
| Network        | A reachable PC; start on the same network.                                                  |

{% hint style="info" %}

Intel Macs and NVIDIA GameStream are unsupported. HDR, codecs and frame rates
need compatible hardware. Glimmer does not install PC display drivers. For
Tailscale, enter the PC's address; [pair securely](SECURITY.md#pairing).

{% endhint %}

For iPhone and iPad, install the
[mobile display modes](HOST_SETUP.md#pick-your-file) on the PC. Native selects
from those listed modes, including portrait, Split View and Stage Manager sizes.
Touch controls work without a controller.

HEVC and AV1 on iPhone and iPad require hardware decoding support. HDR needs a
compatible PC and HDR display; unsupported formats fall back to a supported
format. See [display and video choices](guides/STREAMING.md).
