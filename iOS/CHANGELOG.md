# Changelog

## 2026.10.8 (build 3, unreleased)

- Streams on an external display show the whole picture without cropping when
  the display has a different shape.
- iPhone and iPad can send the streamed picture to a connected display while
  keeping controls on the device. iPad streams also fit Stage Manager windows.

- Streams show the whole picture without cropping when the display or window has
  a different shape.

- iPhone and iPad releases now use Glimmer's shared calendar version.

- Forget a PC from Settings and pair again after resetting Sunshine. Other saved
  PCs are preserved, and forgetting stays unavailable during a stream.
- Pairing errors now point to the recovery steps in Settings.

- Pairing no longer asks you to unlock an already available device for unrelated
  connection errors.

- Touch mouse stays available alongside a controller. Turn it off in Input
  settings to prevent accidental screen input while playing.

- Thumbstick mouse movement is smoother, with finer control for small movements.

- Use a controller to navigate Glimmer's menus and settings. Game input stays
  with the PC while you play.

- Stream settings and the PC setup guide explain when games need a 16:9 mode and
  which virtual display setups need the sample configuration.
