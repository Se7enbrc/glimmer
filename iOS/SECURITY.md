# Security

Report vulnerabilities privately through the
[shared security policy](../docs/SECURITY.md#reporting). Include the affected
revision, what happened and steps to reproduce it. Do not post keys, PINs,
certificates, provisioning profiles or private logs.

The iOS app is in development. Shared engine issues and platform-specific issues
both belong in the
[Glimmer private reports](https://github.com/Se7enbrc/glimmer/security/advisories/new).
